# Ứng dụng Quản lý thư viện sách cá nhân

Project Android Studio viết bằng **Java và XML**, đáp ứng yêu cầu đề bài quản lý sách trong bộ nhớ bằng `ArrayList<Book>`.

## Cách chạy

1. Mở thư mục này bằng Android Studio.
2. Chờ Gradle Sync hoàn tất, chọn emulator hoặc điện thoại Android (API 23 trở lên).
3. Nhấn Run.

Tài khoản đăng nhập: `admin` / `123456`.

## Chức năng

- Đăng nhập, kiểm tra rỗng và sai thông tin.
- Danh sách 3 sách mẫu cùng thống kê tổng, đã đọc, chưa đọc xong.
- Thêm sách với thể loại, trạng thái, đánh giá và ghi chú.
- Xem chi tiết; đổi đánh giá, đánh dấu đã đọc hoặc xóa sách.
- Dữ liệu được giữ trong lúc ứng dụng chạy; đóng hẳn ứng dụng sẽ trở lại dữ liệu mẫu, đúng phạm vi đề bài.
